# Construbem – site

Site da **Construbem Materiais de Construção e Construtora**, Serra Alta/SC.

Página única em HTML, CSS e JavaScript puro (sem build). Abra `index.html` no navegador ou publique no GitHub Pages.

## Seções
- Casa montável em 7 etapas, da fundação ao acabamento
- Parede de produtos por categoria
- Esquadria sob medida com desenho e medidas ao vivo
- Calculadora de obra (paredes, contrapiso/laje, pintura)
- Construtora, ofertas, entrega, perguntas e contato
- Lista da obra enviada pelo WhatsApp
